# pilot (plugin)

Install (replace OWNER with the GitHub owner of the pilot repository):

```text
/plugin install pilot --marketplace OWNER/pilot
```

This folder is what Claude Code installs. It contains the skills, agents, hooks, workflows, output style, templates, the `pilot.js` helper, and the plugin's eval cases.

Documentation, tests, the benchmark and design documents live in the repository root and are not installed. See ../README.md.
